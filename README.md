# fair-rise-bakery
A concept website for Fair Rise, a high-protein bakery franchise that hires people coming home from incarceration. I built it as a clickable MVP to test the idea with potential partners, franchisees and job applicants.

**Live site:** https://nievesrl21.github.io/fair-rise-bakery/

## What it does

Five linked pages, each written for a different audience:

- **Home:** the mission, the protein-packed menu and the fair chance hiring model
- **Hiring:** what employees get (paid training, transport, a peer support network) and an application form
- **Franchise:** the franchise model for mission-aligned operators, with an inquiry form
- **Donate:** partner organizations working on reentry in Chicago
- **Mailing list:** sign-up, current locations and "find out where we'll be next"

The forms are front-end only. They don't send or store any data.

## How I built it

- Designed the brand, logo and copy, then built and iterated the pages with Claude through several rounds of feedback (warmer palette, food-centric visuals, product names tied to the mission)
- Plain HTML, CSS and JavaScript in single self-contained files, with images embedded so each page works offline
- Hosted on GitHub Pages

## Status

Concept project (2026). Fair Rise is not an operating business.
